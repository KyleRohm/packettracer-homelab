# Cisco Packet Tracer Networking Home Lab

This repository features a collection of networking labs covering network configuration, switching, routing, troubleshooting, and connectivity verification, with step-by-step documentation and practical evidence.

## Overview

This project focuses on developing practical networking skills through network design, device configuration, connectivity testing, troubleshooting, and technical documentation.

Configuration commands will be included to document the process and screenshots will serve as verification the steps are completed.

The goal is to build a practical networking portfolio that demonstrates skills relevant to entry-level IT support, network support, infrastructure administration, and future cybersecurity roles.

## Objectives

- Build and document network topologies using Cisco Packet Tracer.
- Develop an understanding of IPv4 addressing, subnetting, and default gateways.
- Configure and verify Cisco switches and routers using Cisco IOS CLI commands.
- Understand Ethernet switching, VLANs, trunking, and inter-VLAN routing.
- Configure routing and common network services where applicable.
- Troubleshoot network connectivity issues using a systematic diagnostic process.
- Apply networking security and device-management best practices.
- Document configurations, verification procedures, troubleshooting steps, and lessons learned.
- Maintain a professional, version-controlled record of hands-on networking projects.

Specific device models, software versions, interface assignments, and addressing schemes will be documented within the corresponding lab.

## Network Architecture

The repository will progress from small, isolated network topologies toward more complex routed and switched environments.

Depending on the lab, topologies may include:

- End devices connected through Ethernet switches.
- Separate IP networks connected by routers.
- VLANs used to segment broadcast domains.
- Inter-VLAN routing between logically separated networks.
- Network services such as DHCP and DNS.
- Management and security configurations for network devices.

Each lab will include a topology diagram or screenshot where appropriate, along with an IP addressing table when applicable.

## Lab Documentation Standards

Each lab will include the sections relevant to its objectives:

1. Overview and objectives
2. Lab environment and device inventory
3. Network topology and IP addressing
4. Prerequisites
5. Step-by-step configuration
6. Cisco IOS commands and configuration explanations
7. Verification and testing
8. Troubleshooting and corrective actions
9. Security considerations and best practices
10. Key concepts learned
11. Skills demonstrated
12. Screenshots and references

Configuration examples will be distinguished from configurations actually applied in Packet Tracer. Verification results will only be recorded when supported by observed output or other evidence.

## Screenshots and Evidence

Screenshots will be used to demonstrate the topology, device configurations, command output, and connectivity tests performed during each lab.

Images will be stored in the relevant lab's `screenshots/` directory. Proposed screenshot filenames will be identified in the documentation before they are captured.
